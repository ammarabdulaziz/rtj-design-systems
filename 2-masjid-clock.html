Masjid
Clock

Every masjid in Doha has one: the LED board on the wall showing salah times in amber digits. RTJ is about showing up on time, so this system turns that board into the app's main object. Time gets its own light. Everything else is quiet, dense and exact.

Shape

Tight radius ladder

Boards and cards 10px, buttons 8px, chips and toggles 4–6px. Square line caps on icons. No pills anywhere: pills read soft, and this system isn't soft.

Depth

Borders, not shadows

1px rules separate everything. The only "depth" is the LED board, which is darker than its surroundings, and the dragged row in the rotation list.

Motion

Fast or none

State changes at 100ms. The amber dot blinks in 1.2s steps only while something is unconfirmed or live. Countdown digits change in place, never slide or flip.

04

Rules

Hold these when building screens not shown here.

Do

  • Use amber only for time: countdowns, "live", "unconfirmed". If it isn't about time, it isn't amber.
  • Keep LED boards dark in both modes. They're objects, not themed surfaces.
  • Put every number in tabular figures; use 62%-width Archivo for big stats.
  • Pair every status color with an LED dot and a word.
  • Make the primary action bone-on-black (or black-on-marble), never colored.

Don't

  • Don't use Doto for anything except digits on a board. It's a display face, not text.
  • Don't add shadows to cards. Use a border.
  • Don't use red for destructive buttons and points in the same view; destructive uses an outline.
  • Don't add Islamic pattern ornament. This system's identity is the clock.
  • Don't animate digits (flip, slide, count up).
